## ペルソナ確定 (今回のターゲット)

**自分の手で事業を動かしている経営者**

- 一人法人代表 〜 社員数人 〜 数十人規模
- 売上ボリュームゾーン: 数千万 〜 数億円
- 一部例外: 小坂さん経由の数十億規模も混在
- 共通項: **自分が止まると事業も止まる。時間がボトルネック。生産性が直接成果になる**
- AIへの認知: 漠然と「やった方がいい」程度。**自社で何が変わるかの像が描けていない**
- 50万マスタークラスに即決はしないが、半年で人生変わるなら払う金銭感覚

**小坂さんFBの採用部分**: 「想像できていない読者を感情で動かす」
**不採用部分**: 「ベネフィット直球にしろ」(SaaSテンプレ化リスク回避のため、各案で訴求軸を分散)

## 5案

### A案 — ベネフィット型 (経営者の未来提示)

- **eyebrow**: Claude Code 実践セミナー
- **主タイトル**:
  ```
  あなたが寝ている間に、
  AIが社員5人分の仕事を終えている。
  ```
- **サブコピー**:
  ```
  半年で、自分が止まっても回る事業へ。
  その設計図を、2時間でお見せします。
  ```
- **補足**: * Claude Code は、ChatGPT より仕事向けに進化した次世代の AI です。
- **設計意図**: 経営者最大の悩み「自分が止まると事業も止まる」を逆転させる未来像を提示。「設計図」という言葉で「具体的な方法論がある」感を出す
- **想像できていない経営者を動かす方向**: ベネフィットの像を具体的に渡す

### B案 — 恐怖型 (小坂さんFB直球)

- **eyebrow**: Claude Code 実践セミナー
- **主タイトル**:
  ```
  3年後、AIを使う経営者と、
  使われる経営者に分かれる。
  ```
- **サブコピー**:
  ```
  いま動いている経営者だけが、
  半年後に景色が変わる側にいる。
  ```
- **補足**: * Claude Code は、ChatGPT より仕事向けに進化した次世代の AI です。
- **設計意図**: 「使う/使われる」で二分化。3年後の格差を提示してFOMO刺激
- **想像できていない経営者を動かす方向**: 未来の自分が取り残されるイメージを与える

### C案 — 物語改良型 (現コピーを残しつつ具体化)

- **eyebrow**: Claude Code 実践セミナー
- **主タイトル**:
  ```
  半年前、私もAIを使えませんでした。
  いま、社員を雇わずに事業が伸びています。
  ```
- **サブコピー**:
  ```
  自分の手で動かしてきた経営者へ。
  半年で起きた変化を、2時間でお見せします。
  ```
- **補足**: * Claude Code は、ChatGPT より仕事向けに進化した次世代の AI です。
- **設計意図**: 現コピーの物語型を維持しつつ「AIで仕事をしている」を「社員を雇わずに事業が伸びている」に具体化。経営者の財務感覚にも刺さる
- **想像できていない経営者を動かす方向**: 「社員雇わずに伸びる」という経営者ど真ん中のベネフィットを提示

### D案 — 数字型

- **eyebrow**: Claude Code 実践セミナー
- **主タイトル**:
  ```
  ひとりで、社員5人分の仕事を。
  経営者のための、AI 革命。
  ```
- **サブコピー**:
  ```
  自分が止まれば事業も止まる。
  その構造を半年で壊した実例を、2時間で。
  ```
- **補足**: * Claude Code は、ChatGPT より仕事向けに進化した次世代の AI です。
- **設計意図**: 「5人分」で目を止める。主語を「経営者のための」に明示してターゲット呼びかけ
- **想像できていない経営者を動かす方向**: 数字インパクト + ターゲット明示で「自分の話だ」と認識させる

### E案 — 質問型 (痛み直撃)

- **eyebrow**: Claude Code 実践セミナー
- **主タイトル**:
  ```
  あなたの会社、あと何年、
  あなた依存で回しますか?
  ```
- **サブコピー**:
  ```
  半年で、自分の手から離れても回る事業へ。
  経営者のための AI セミナー、2時間。
  ```
- **補足**: * Claude Code は、ChatGPT より仕事向けに進化した次世代の AI です。
- **設計意図**: 経営者の最も痛い問いを直接投げる。「あなた依存」の言葉で当事者意識を喚起
- **想像できていない経営者を動かす方向**: 痛みを直接刺して「読み進めないと不安」状態を作る
