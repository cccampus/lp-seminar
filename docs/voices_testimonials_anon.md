# Voices 用 匿名化テスティモニアル（実名・社名は完全除去・役職は一般化）

> 出典: 受講者アンケート（Takka の過去AIクリエイティブ講座）。Takka 指示：
> **実名・所属(会社名)は絶対に出さない。役職はそのままだと会社が特定されるため一般化して使う。**
> ここでは「講師の教え方・密度・実践性」を語る汎用的な声のみ抜粋（特定ツール名に依存しない一般評価）。
> Voices セクション（PC=並べる / スマホ=Tinder風スワイプカード）に流用。各カードは persona_01〜04.png（架空人物）と組み合わせる。

## 厳守ルール（実装エージェントへ）
- 上記コメント・役職以外を勝手に足さない。**実名・会社名・部署の固有名は一切出さない**
- 役職はこの一般化版のまま（元データの "A³"/"EVOKE" 等の社名・部署コードは使用禁止）
- 「副業/稼ぐ/月◯万」等のNGワード禁止
- 顔写真は persona_01〜04.png（架空）を使用。実在受講者の顔写真は使わない
