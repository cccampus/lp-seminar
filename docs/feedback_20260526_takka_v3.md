## 6. 「参加された方のリアルな声」(Voices)
- **6-1 [CODE]** 横スクロールバーがダサい → **自動で横スクロール(マーキー)**。hoverで掴める程度はOKだが、変なドラッグ&ドロップ/触れる仕様は不要。基本「勝手に流れてる」
- **6-2 [DESIGN]** 四角い枠がダサい → **お客様の声をかっこよく装飾**
- **6-3 [IMG]** 架空ペルソナの人物画像でOK。**背景と人物がレイヤー分離**（人物の頭の上半分が白背景から飛び出す切り抜き合成）。上に小さくプロフィール＋コメント。PC=並べる / スマホ=横スワイプ
- 参照: Pinterest 405324035233158997 / 666392076143351661 / 991143830499255993
