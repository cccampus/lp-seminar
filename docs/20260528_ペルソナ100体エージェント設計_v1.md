## 1. ペルソナ100体の分布

紀洋さん指定 + 小坂さんFB 反映:
- 中心ペルソナ = 自分の手で事業を動かしている経営者
- ボリュームゾーン = 数千万〜数億規模
- 一部 = 数十億規模も含む (小坂さん経由)
- 補助 = 副業フリーランス志向サラリーマン (紀洋さん発言「繋がってはいけるんじゃないか」)

| 層 | 体数 | 内訳 |
|---|---|---|
| 一人法人代表 (年商数千万〜数億) | 60 | 30代後半〜50代、創業3年以上、社員0〜2人 |
| 社員数人規模経営者 (年商数億〜十数億) | 25 | 40代〜50代、社員3〜10人、自分も現場 |
| 社員10名以上 (年商十数億〜数十億) | 10 | 40代〜60代、社員10〜50人、現場感ありの経営者 |
| 副業フリーランス志向サラリーマン | 5 | 20代後半〜30代、独立志向、年収500〜900万 |
| **合計** | **100** | |

業種分布 (どの層にもまんべんなく入れる):
- コンサル / 士業 (税理士・弁護士・社労士・行政書士): 20体
- IT・Web制作・SaaS: 15体
- 飲食・小売店舗経営: 15体
- 医療・歯科・整体・整骨院: 10体
- 不動産・建設: 10体
- 教育・スクール・コーチング: 10体
- 製造業・卸: 8体
- メディア・編集・クリエイティブ: 7体
- その他サービス業: 5体

AIリテラシー分布:
- ChatGPT 触ったことなし: 30体
- ChatGPT 月1〜数回: 40体
- ChatGPT 週1以上: 20体
- Claude / Cursor / Copilot も触ってる: 10体

## 4. 実行方法

### Option 1: Claude Code Agent tool で並列起動 (推奨)

```ts
// scripts/persona-test.ts
import { spawn } from "child_process";

const personas = JSON.parse(fs.readFileSync("personas-100.json", "utf-8"));
// 並列度: 10体ずつ x 10バッチ (リソース節約)
for (let batch = 0; batch < 10; batch++) {
  const slice = personas.slice(batch * 10, (batch + 1) * 10);
  await Promise.all(slice.map(p => runAgent(p)));
}
```

各エージェントは Claude Sonnet 4.6 で実行 (Opus は過剰、Sonnet で十分)。
レスポンスは `personas-100-results.json` に集約。

### Option 2: 単一セッションで順次評価 (シンプル)

1つのAgent tool に「100体分のJSONを順に評価して全結果をJSON配列で返せ」と投げる。
- メリット: シンプル、1回の Agent 呼び出しで完結
- デメリット: 1リクエストで100体分の評価=出力長くなる、品質低下リスク

→ **Option 1 推奨**。10並列バッチで安定運用。

### Option 3: Telegram Bot から発火 (将来)

Mac mini の x-auto 並みに `/persona-test {lp-url}` で発火 → 自動集計 → Telegram に結果通知。
**今回は Option 1 で十分**。Bot 化は別フェーズ。

## 6. GO / NOGO 判定基準

| 指標 | 閾値 | 判定 |
|---|---|---|
| 勝者案の avg click_intent | ≥ 70 | GO |
| 勝者案の bounce_rate | ≤ 10% | GO |
| 勝者案の segment 偏り (全層で best/2nd) | 4層中3層以上で上位 | GO |

3条件全て満たさなければ **再度コピー案を作り直し PDCA**。

## 8. 注意点

- **エージェントの偏り**: Claude 自身の世界観/価値観が出る可能性。プロンプトで「本音、忖度なし、経営者としてのリアルな反応」を強調
- **AI生成ペルソナの限界**: 実在の経営者のFBに完全には置き換わらない。最終判断は紀洋さん + 小坂さん等の実在経営者
- **コスト**: 100体 × Sonnet 4.6 で約 ¥500〜1,000 (Anthropic API直叩き想定、Max枠でも消費可)
- **再現性**: 同じペルソナでも temperature による揺らぎあり。重要評価は temperature=0 推奨
